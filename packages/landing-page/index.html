FAQ

Does NowForge access my ServiceNow data?

The browser extension makes REST calls to your instance using your active browser session. None of that data is sent to NowForge servers. The AI assistant (Pro) sends your script directly to Anthropic or OpenAI using your own API key.

Will it work with my old PDI?

Yes for everything except the on-instance Enterprise app, which requires Yokohama or later. The browser extension works on all SN versions.

Can I write my own commands or rules?

Yes — the Plugin Marketplace lets you publish custom commands, quality rules, snippets, AI prompts, pipeline templates, and Learning Mode tips. Plugins are JSON, easy to author, free to share.

Is the source available?

The core library, browser extension, VS Code extension, ESLint plugin, and MCP server are MIT-licensed and on GitHub. The cloud sync service is hosted by us.

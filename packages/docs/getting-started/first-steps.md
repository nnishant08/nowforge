# First steps

Once the browser extension is loaded:

1. **Visit a ServiceNow page.** The toolbar icon turns into a colored circle showing the instance initials. The favicon and tab title pick up the env color too.
2. **Press ⌘K (Ctrl+K on Win/Linux).** The command bar appears. Type `/inc` and hit Enter to jump to incidents.
3. **Click the side-panel icon** (◫) in the popup. Five tabs open: Nav, Scripts, Updates, Deploy, Debug.
4. **Right-click a field label** on any form. Custom menu with field metadata + copy actions.
5. **Open Options.** Configure environment colors, custom env detection rules, and (if you've upgraded to Pro) your AI provider's API key.
